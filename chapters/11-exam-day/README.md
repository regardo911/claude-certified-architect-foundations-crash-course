# Chapter 11: exam day

[ritual-card.md](ritual-card.md) is Chapter 11's card: the setup checklist, the clock plan, the morning timeline and the after-note, plus the tech check from the same chapter. [last-24-hours.md](last-24-hours.md) is Appendix A's seven-step checklist for the day before.

Print one of each ([ritual-card.pdf](ritual-card.pdf), [last-24-hours.pdf](last-24-hours.pdf)). Run the setup checklist the night before, then again right before check-in; the card has a column for each.

The clock plan has two cases because the book can't promise the exam lets you flag and come back. The screen before your first question tells you which one you got. Tick it, and play that plan.

Chapter 11 calls it ready when "you can run the whole exam-day operation off this one card without improvising".
